## 4️⃣ Melhorias visuais essenciais (rápidas)

### 🎨 1. Status com cores fixas (badge)

Use sempre o mesmo padrão:

| Status       | Cor         |
| ------------ | ----------- |
| Pendente     | 🔴 Vermelho |
| Em andamento | 🟡 Amarelo  |
| Concluída    | 🟢 Verde    |

```jsx
<Badge color="red">Pendente</Badge>
```

---

### ⏱️ 2. Dias em manutenção como ALERTA visual

Isso é crítico no line haul.

* Até 2 dias → cinza
* 3 a 5 dias → amarelo
* +5 dias → vermelho pulsando 🚨

Exemplo visual:

```txt
⏱️ 228 dias parado 🚨
```

👉 Esse número precisa ser **maior que o resto do texto**.

## 5️⃣ Compactar os cards (ganhar leitura rápida)
