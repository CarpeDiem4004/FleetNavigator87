# 6️⃣ **Como montar o backend (Supabase / Railway)**

### **Query base para consumo filtrado**

```sql
select 
  placa,
  motorista,
  base,
  projeto,
  data_abastecimento,
  litros,
  valor,
  operadora
from abastecimentos
where data_abastecimento between :data_inicio and :data_fim
and (:base is null or base = :base)
and (:projeto is null or projeto = :projeto)
and (:placa is null or placa = :placa)
and (:operadora is null or operadora = :operadora)
order by data_abastecimento desc;
```

### **Query para ranking de veículos**

```sql
select placa, sum(litros) as litros, sum(valor) as valor
from abastecimentos
where data_abastecimento between :data_inicio and :data_fim
group by placa
order by valor desc;
```

### **Query para ranking de bases**

```sql
select base, sum(valor) as total
from abastecimentos
where data_abastecimento between :data_inicio and :data_fim
group by base
order by total desc;
```

### **Comparativo mensal**

```sql
select 
  date_trunc('month', data_abastecimento) as mes,
  sum(valor) as total
from abastecimentos
where data_abastecimento between :inicio and :fim
group by mes
order by mes;
```
