1. Diagnóstico Resumido

CRÍTICO: Conflito entre duas configurações do cliente Supabase está causando falha na resolução do hook useState do React.
O problema faz com que o React não consiga inicializar corretamente o estado dentro do contexto de autenticação.

⸻

2. Causa-raiz (com arquivo/linha)

Arquivo: client/src/context/SupabaseAuthContext.tsx:43

const [user, setUser] = useState<User | null>(null);  ❌ hook não resolvido corretamente

Problema subjacente:
O projeto possui duas implementações conflitantes do cliente Supabase:
	•	❌ client/src/lib/supabaseClient.ts:21-23 (ainda com JWT hardcoded)
	•	✅ client/src/lib/supabase-compat.ts (versão corrigida e compatível)

O hook useSupabaseAuth está importando do arquivo incorreto:

// ❌ ERRADO em client/src/hooks/useSupabaseAuth.ts:2
import { supabase } from '@/lib/supabaseClient'; // Tokens hardcoded!

Isso cria conflito de dependências React, fazendo useState ser resolvido como null em vez da função esperada.

⸻

3. Correção Sugerida

Consolidar para usar apenas supabase-compat.ts

Diff 1: Corrigir client/src/lib/supabaseClient.ts

- export const supabaseUrl = import.meta.env.VITE_SUPABASE_URL || 'https://hvsmxxqkuyjhpsiojupb.supabase.co';
- export const supabaseAnonKey = import.meta.env.VITE_SUPABASE_ANON_KEY || 'eyJhbGciOiJI...';
- export const supabaseServiceKey = import.meta.env.VITE_SUPABASE_SERVICE_KEY || 'eyJhbGciOiJI...';
+ // Re-exportar do arquivo principal corrigido
+ export * from '@/lib/supabase-compat';

Diff 2: Corrigir client/src/hooks/useSupabaseAuth.ts

- import { supabase } from '@/lib/supabaseClient';
+ import { supabase } from '@/lib/supabase-compat';
