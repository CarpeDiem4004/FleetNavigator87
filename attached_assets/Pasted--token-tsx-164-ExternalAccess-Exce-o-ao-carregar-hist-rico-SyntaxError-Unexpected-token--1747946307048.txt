significa que seu código esperava receber um JSON de uma API, mas na verdade recebeu um HTML como resposta. Isso normalmente acontece quando:

🔍 Causas mais comuns:
URL incorreta ou mal configurada:

Ex: Você tentou buscar dados de uma rota /api/historico mas acabou recebendo o HTML da página inicial, porque a rota não existe ou está errada.

O servidor retornou uma página de erro (como 404 ou 500)

Mas você tentou fazer response.json() mesmo assim.

Está tentando acessar um arquivo estático como JSON, mas ele é HTML.

✅ Como corrigir:
1. Verifique a URL da requisição:
Confirme que a URL que você está usando realmente retorna um JSON.

Exemplo:

useEffect(() => {
  const loadHistorico = async () => {
    try {
      const res = await fetch('/api/historico');

      const contentType = res.headers.get("content-type");
      if (!res.ok || !contentType?.includes("application/json")) {
        const html = await res.text();
        console.error("Resposta inesperada (esperava JSON):", html);
        throw new Error("Resposta inválida");
      }

      const data = await res.json();
      setHistorico(data);
    } catch (err) {
      console.error("[ExternalAccess] Exceção ao carregar histórico:", err);
    }
  };

  loadHistorico();
}, []);
