## 🎯 PROMPT PARA USAR NO REPLIT AI

```
Contexto:
Tenho um sistema web (Node.js + Supabase) que possui um painel BIP
(Histórico de BIP por Veículo). As informações de BIP são alimentadas
por uma planilha do Google Sheets.

Planilha:
- Link: https://docs.google.com/spreadsheets/d/1k5C937ewZBgv_TzNuXyBLlCioA8v_3Bhy7L1ZoU8_2I
- Aba: "BIP's Murici"
- Colunas principais:
  - SHP_LG_VEHICLE_PLATE_ID (placa)
  - Cadastro_veic
  - SHP_COMPANY_NAME
  - Facility
  - DATA_ULTIMO_BIP

Objetivo:
Criar um serviço automático no backend que:
1) Acesse a planilha usando Google Sheets API (Service Account)
2) Leia todos os registros da aba "BIP's Murici"
3) Atualize ou insira os dados em uma tabela do Supabase chamada `bip_veiculos`
4) Use UPSERT baseado na placa
5) Execute essa sincronização automaticamente a cada 30 minutos
6) Não depender do frontend para buscar dados do Google

Requisitos técnicos:
- Node.js
- google-spreadsheet
- node-cron
- Supabase JS Client
- Usar variáveis de ambiente para credenciais
- Criar função `syncBIP()` isolada
- Criar job cron: */30 * * * *

Estrutura esperada da tabela `bip_veiculos`:
- placa (unique)
- cadastro_veic
- empresa
- facility
- data_ultimo_bip
- atualizado_em

Resultado esperado:
- Código organizado
- Comentado
- Seguro
- Pronto para produção
- Logs claros de execução
- Tratamento básico de erro

Antes de codar:
Analise o projeto atual, verifique onde encaixar o job (ex: server.js,
index.js ou pasta services/jobs) e implemente da forma mais limpa possível.
```
