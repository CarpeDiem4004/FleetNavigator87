# 1️⃣ MODELAGEM NO SUPABASE (ESSENCIAL)

## 📌 Tabela `bases`

```sql
create table bases (
  id uuid primary key default uuid_generate_v4(),
  nome text not null,
  operacao text,
  created_at timestamp default now()
);
```

---

## 📌 Tabela `profiles` (vincula login à base)

> Essa tabela estende o `auth.users`

```sql
create table profiles (
  id uuid primary key references auth.users(id) on delete cascade,
  nome text,
  base_id uuid references bases(id),
  tipo text, -- admin | base
  created_at timestamp default now()
);
```

👉 **É aqui que está o segredo**
`profiles.base_id` define **para onde o login vai cair**.

# 4️⃣ APÓS LOGIN → BUSCAR BASE DO USUÁRIO

👉 **Esse trecho é o mais importante**

```js
const user = data.user;

const { data: profile } = await supabase
  .from("profiles")
  .select("base_id, tipo")
  .eq("id", user.id)
  .single();
```

# 7️⃣ RLS NO SUPABASE (SEGURANÇA DE VERDADE)

### 📌 Policy para bases só verem seus dados

```sql
create policy "Base só vê seus dados"
on veiculos
for select
using (
  base_id = (
    select base_id from profiles where id = auth.uid()
  )
);
```
