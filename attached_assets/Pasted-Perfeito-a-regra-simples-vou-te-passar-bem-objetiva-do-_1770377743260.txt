## 🎯 Regra de negócio (definitiva)

**Horário solicitado → Data de consulta do abastecimento**

1. **Se o abastecimento for solicitado ATÉ 16:00**

   * 👉 consultar **na data atual**

2. **Se o abastecimento for solicitado APÓS 18:00**

   * 👉 consultar **na data atual + 1 dia (D+1)**

3. **Entre 16:01 e 17:59**

   * 👉 mantém **data atual** (ou ignora regra, conforme você quiser)

---

## 🧠 Lógica clara (para a IA entender)

* O sistema deve **olhar o horário selecionado no filtro**
* Comparar com `16:00` e `18:00`
* Definir automaticamente a **data base de consulta**

---

## 🧩 Exemplo em JavaScript (frontend ou backend)

```js
function calcularDataConsulta(horarioSelecionado) {
  const hoje = new Date();
  const [hora, minuto] = horarioSelecionado.split(':').map(Number);

  // Cria um objeto Date só com hora/minuto
  const horario = new Date();
  horario.setHours(hora, minuto, 0, 0);

  const limite16 = new Date();
  limite16.setHours(16, 0, 0, 0);

  const limite18 = new Date();
  limite18.setHours(18, 0, 0, 0);

  // Até 16h → data atual
  if (horario <= limite16) {
    return hoje;
  }

  // Após 18h → D+1
  if (horario >= limite18) {
    const amanha = new Date(hoje);
    amanha.setDate(hoje.getDate() + 1);
    return amanha;
  }

  // Entre 16:01 e 17:59 → data atual
  return hoje;
}
```
