Erro parsing JSON: SyntaxError: Unexpected token '<', "<!DOCTYPE "... is not valid JSON
significa que você tentou usar JSON.parse() para processar uma resposta HTML (provavelmente um erro de servidor ou redirecionamento), quando esperava receber JSON.

🎯 Causa mais comum:
Você está fazendo uma requisição fetch ou XMLHttpRequest para uma URL que:

Retornou uma página HTML (geralmente um erro 404, 500 ou um redirecionamento para login) em vez de retornar JSON como esperado.

Em seguida, você tentou fazer JSON.parse(resposta) e deu erro, porque a resposta começa com <!DOCTYPE html>.

✅ Como resolver
1. Verifique a URL que está sendo requisitada
Verifique se está correta. Pode haver:

Um endpoint errado (ex: /api/algum-endpoint incorreto),

Um problema de CORS,

Um erro de autenticação (token vencido/redirecionamento para login),

Um erro de backend (500 ou 404).

2. Verifique o conteúdo da resposta antes de fazer JSON.parse()
Exemplo com fetch:

ts

fetch('/api/partner-access')
  .then(async (res) => {
    const contentType = res.headers.get('content-type');
    if (!res.ok) {
      const text = await res.text(); // captura o HTML de erro
      throw new Error(`Erro ${res.status}: ${text}`);
    }
    if (contentType && contentType.includes('application/json')) {
      return res.json(); // segura
    } else {
      const text = await res.text();
      throw new Error(`Resposta inesperada: ${text}`);
    }
  })
  .then((data) => {
    // use os dados JSON aqui
  })
  .catch((err) => {
    console.error('Erro na requisição:', err);
  });
3. Se estiver usando XMLHttpRequest:
Antes de fazer JSON.parse(xhr.responseText), verifique xhr.status e o tipo de conteúdo:

xhr.onload = function () {
  if (xhr.status === 200) {
    try {
      const contentType = xhr.getResponseHeader('Content-Type');
      if (contentType && contentType.includes('application/json')) {
        const data = JSON.parse(xhr.responseText);
        // usar `data`
      } else {
        console.error('Resposta não é JSON:', xhr.responseText);
      }
    } catch (e) {
      console.error('Erro ao fazer parse do JSON:', e.message);
    }
  } else {
    console.error('Erro HTTP:', xhr.status, xhr.responseText);
  }
};
