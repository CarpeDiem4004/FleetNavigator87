O ChatGPT disse:
Esse erro está vindo do componente <Select.Item /> da biblioteca Radix UI e a mensagem é bem direta:

"A <Select.Item /> deve ter uma prop value que não seja uma string vazia."

🧨 O que está acontecendo
Você provavelmente está fazendo algo assim:

tsx
Copiar
Editar
<Select.Item value="">
  <Select.ItemText>Selecione uma opção</Select.ItemText>
</Select.Item>
E o Radix está dizendo que isso não é permitido, porque o valor "" (string vazia) é reservado para limpar o valor do select.

✅ Como corrigir
Você tem duas opções:

✅ 1. Usar um Select.Placeholder separado em vez de usar <Select.Item value="">
tsx
Copiar
Editar
<Select.Root value={valor} onValueChange={setValor}>
  <Select.Trigger>
    <Select.Value placeholder="Selecione uma opção" />
  </Select.Trigger>

  <Select.Content>
    <Select.Viewport>
      <Select.Item value="opcao1">
        <Select.ItemText>Opção 1</Select.ItemText>
      </Select.Item>
      <Select.Item value="opcao2">
        <Select.ItemText>Opção 2</Select.ItemText>
      </Select.Item>
    </Select.Viewport>
  </Select.Content>
</Select.Root>
⛔ Evitar isso:
tsx
Copiar
Editar
<Select.Item value="">
  <Select.ItemText>Selecione uma opção</Select.ItemText>
</Select.Item>
🧪 Dica extra
Se você estiver carregando opções dinamicamente, garanta que nenhuma delas venha com value: "", como no exemplo abaixo:

tsx
Copiar
Editar
{opcoes.map(opcao => (
  <Select.Item key={opcao.id} value={opcao.valor ?? ""}> // <-- isso pode causar erro

  </Select.Item>
))}
