✅ PROMPT – Importação Correta da Planilha de Indicadores de Manutenção (.xlsx)

Quero que você implemente um importador completo de planilha Excel (.xlsx) no meu backend Express do projeto Murici On Fleet 2.0.

Siga exatamente as instruções abaixo e gere todo o código pronto.

1. OBJETIVO

Criar uma rota:

POST /api/manutencoes/upload


Que faz:

Recebe um arquivo Excel (.xlsx) via Multer

Lê a planilha usando xlsx

Valida todas as colunas obrigatórias

Mapeia cada coluna para o formato da tabela no Supabase

Converte datas e valores corretamente

Gera um array JSON limpo

Faz upsert na tabela manutencoes_historico no Supabase

Retorna um relatório com:

total importado

linhas ignoradas

erros encontrados

2. ESTRUTURA DA TABELA NO SUPABASE

A importação precisa preencher estes campos:

placa
tipo
descricao
valor
status
km
oficina
base
data_manutencao
data_entrada
data_saida
tempo_total

3. NOMES DE COLUNAS DA PLANILHA (ORIGEM)

A planilha enviada pelo cliente pode ter títulos assim:

DATA SAÍDA

TEMPO DE MANUTENÇÃO

Você deve:

✔ aceitar qualquer variação: maiúscula/minúscula
✔ remover acentos
✔ trim()
✔ mapear para os campos do banco

4. REGRAS DE NORMALIZAÇÃO
Datas

Converter tudo para:

YYYY-MM-DD


Aceitar formatos:
dd/mm/yyyy, mm/dd/yyyy, yyyy-mm-dd, datetime do Excel, número serial Excel.

Valores numéricos

Trocar vírgula por ponto

Converter vazio para null

Placa

remover espaços

deixar maiúscula

A IA deve gerar um backend com:

✔ Middleware Multer (somente .xlsx)
✔ Handler usando XLSX para leitura
✔ Função normalizeRow(row)
✔ Função convertDate(value)
✔ Função cleanNumber(value)
✔ Validação: placa obrigatória
✔ array final JSON de registros limpos
✔ Upsert:
supabase
  .from('manutencoes_historico')
  .upsert(dataImportada, { onConflict: 'placa,data_manutencao' })
