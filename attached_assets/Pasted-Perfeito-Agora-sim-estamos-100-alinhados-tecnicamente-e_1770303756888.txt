* tela que não abre
* estado inconsistente

No `AuthContext`:

```ts

```

📌 Sem exceção
📌 Sem “tentativa otimista”

---

### 🧼 3️⃣ LIMPAR COOKIE QUANDO A SESSÃO NÃO EXISTIR

No backend:

```ts
if (!req.session.user) {
  req.session.destroy(() => {})
  res.clearCookie("connect.sid")

}
```
