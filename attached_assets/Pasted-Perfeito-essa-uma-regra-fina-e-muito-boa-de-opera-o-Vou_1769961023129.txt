# 🧱 1. PRÉ-REQUISITO NO SUPABASE

Na tabela `veiculos`:

```sql
cartao_abastecimento TEXT NULL
```

👉 Regra simples:

* `NULL` ou vazio = **não tem cartão**
* preenchido = **cartão vinculado**

# 🔄 2. DADOS QUE O BOLSÃO PRECISA RECEBER

Endpoint já deve retornar isso:

```sql
SELECT
  id,
  placa,
  status_operacional,
  cartao_abastecimento
FROM veiculos
WHERE base_id = :base_id
AND status_operacional != 'EM_MANUTENCAO';
```

# 🔍 4. REGRA PRINCIPAL (AUTOMÁTICA)

```js
useEffect(() => {
  if (!veiculoSelecionado) return

  if (veiculoSelecionado.cartao_abastecimento) {
    // ✔️ cartão já existe
    setCartaoManual('')

    // ❌ não tem cartão
```

# 🧠 6. FORMATAÇÃO DA PLACA (REAPROVEITANDO PADRÃO)

👉 **Use exatamente a função que você já tem**
Mas se precisar de referência:

```js
function formatarPlaca(valor) {
  return valor
    .toUpperCase()
    .replace(/[^A-Z0-9]/g, '')
}
```

📌 Isso mantém:

* ABC1D23
* AAA1234
