O QUE ESTÁ ACONTECENDO (RESUMO TÉCNICO)

✔️ No computador
	•	Select abre normal
	•	Lista de Projetos e Bases carrega
	•	Dependência Projeto → Base funciona

❌ No celular
	•	Select não abre ou não renderiza
	•	Ou abre “quebrado”
	•	Em alguns casos gera erro de Load failed
	•	Usuário fica travado

📌 Conclusão
O componente de Select que você está usando não é mobile-safe (ou não está configurado para touch).

⸻

🔴 CAUSA REAL (SEM ENROLAÇÃO)

Normalmente é um desses cenários (ou todos):

1️⃣ Select customizado (Radix / ShadCN / Headless UI)

Esses componentes:
	•	Funcionam bem com mouse
	•	Quebram em touch se não tiver:
	•	portal
	•	z-index
	•	position: fixed
	•	scroll habilitado

⸻

2️⃣ Dropdown abre FORA DA VIEWPORT no mobile

No celular:
	•	Tela menor
	•	Teclado sobe
	•	Dropdown tenta abrir “para baixo”
➡️ Resultado: fica invisível

⸻

3️⃣ Falta de fallback mobile

No mobile, o ideal é:
👉 usar <select> nativo
Não dropdown customizado.

⸻

✅ SOLUÇÃO PROFISSIONAL (USADA EM SISTEMA GRANDE)

🥇 SOLUÇÃO IDEAL (RECOMENDADA)

👉 Desktop: select customizado
👉 Mobile: select nativo do HTML

Detectar mobile:

const isMobile = window.innerWidth <= 768;


⸻

🔧 IMPLEMENTAÇÃO – PROJETO

{isMobile ? (
  <select
    value={project}
    onChange={(e) => setProject(e.target.value)}
    className="input"
  >
    <option value="">Selecione um projeto</option>
    {projects.map(p => (
      <option key={p.id} value={p.id}>
        {p.name}
      </option>
    ))}
  </select>
) : (
  <CustomSelect
    value={project}
    onChange={setProject}
    options={projects}
  />
)}

✔️ Abre teclado nativo
✔️ Lista perfeita no celular
✔️ Zero bug
✔️ UX limpa

⸻

🔧 IMPLEMENTAÇÃO – BASE (DEPENDENTE DO PROJETO)

<select
  disabled={!project}
  className="input"
>
  <option value="">
    {project ? "Selecione a base" : "Selecione um projeto primeiro"}
  </option>
  {bases.map(b => (
    <option key={b.id} value={b.id}>
      {b.name}
    </option>
  ))}
</select>


⸻

🎨 AJUSTES VISUAIS OBRIGATÓRIOS NO MOBILE

select, input {
  font-size: 16px; /* evita zoom no iOS */
  height: 48px;
}

select {
  appearance: none;
}
