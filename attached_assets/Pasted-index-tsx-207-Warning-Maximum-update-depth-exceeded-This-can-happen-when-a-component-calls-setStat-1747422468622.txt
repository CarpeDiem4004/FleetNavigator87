é um erro clássico de loop infinito em setState() dentro do React.

✅ O que significa isso?
Esse erro aparece quando um componente está chamando setState() (ou algo que provoca uma atualização de estado) dentro de um useEffect mal configurado, geralmente assim:

tsx
Copiar
Editar
useEffect(() => {
  setState(algumaCoisa); // ← isso roda a cada render se não tiver dependência
});
Ou então:

tsx
Copiar
Editar
useEffect(() => {
  setState(outroValor); // ← mas `outroValor` muda toda vez → novo render → loop
}, [outroValor]);
